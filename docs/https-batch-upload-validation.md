# 批量上传优化验证

## 实现范围

自动上传串行处理文件，在多个文件之间保留 Wi-Fi Station 和 TLS 连接。
每次扫描只保留 8 个候选索引，窗口处理完成后继续扫描，不以 8 个文件为连接生命周期上限。
音频仍留在 SD，使用 2 KiB 缓冲流式发送；HTTP 断点分片仍为 16 KiB。
服务器通过 `X-Clip-Batch: 1` 保持完整文件之间的连接，旧客户端行为保持兼容。

录音、取消、错误和队列结束仍触发统一清理；复用连接意外断开时只对传输错误重连一次，重新查询服务器确认位置。

## 构建与主机检查

固件基于 `8e7a5fe74b9727bd773c0dfe6ec29bdce2befad1` 的未提交源码快照 revision 4 构建。
完整源码清单、差异、构建日志、ELF、map 和配置保存在本地 `.analysis/https-runtime-0.1.2/batch-upload-v1/`。

- 85 项主机测试：84 通过、1 跳过；其中实际 C 上传逻辑覆盖 13 种适配器场景，启用 ASan/UBSan。
- 镜像签名验证、升级 ZIP 内容、产物哈希、外置 Wi-Fi 补丁和分区检查通过。
- 应用 Flash：827,196 / 933,376 字节，相比此前设备镜像增加 904 字节。
- 静态 RAM：448,214 / 450,560 字节，与此前镜像相同；该数字包含预留堆和栈，不代表运行时峰值。
- 设备读回镜像摘要：`16cceadefb2372fcee14f83f8a89966628fb133952dd4b109bf724ce92b1f013`。

## 设备实测

Clip C7BB 使用原有 Wi-Fi 和公网 HTTPS 接收端，完成应用镜像升级并正常启动，持久配置保留。

| 项目 | 结果 |
| --- | --- |
| 连续上传 | 完成 46 个文件，跨越多个候选窗口 |
| 本轮新增确认数据 | 1,741,809 字节，包含最后一个未完成文件已确认的部分，扣除测试前已有断点 |
| 观测时间 | 368.94 秒，包含启动、扫描、连接和结束清理 |
| 队列整体速率 | 4.61 KiB/s；此前样本约 2.10 KiB/s |
| 大文件持续传输样本 | 约 6.84 KiB/s |
| 连接复用 | 服务器观测的前 46 个完成文件使用相同 TCP 四元组，跨窗口未观察到重新连接 |
| 录音抢占 | 在已传输新分片的自动任务中触发，约 504 ms 进入录音，上传已停止 |
| 录音结束 | 自动任务重新启动；随后主动暂停该任务，单独核对原文件续传 |
| 原文件续传 | 从 1,015,808 字节恢复，完成 1,140,293 字节文件；设备状态与服务器大小、SHA-256 一致 |
| 收尾状态 | IDLE、自动上传关闭、没有活动上传 |

两轮文件组合不同，2.2 倍属于本轮相对于历史样本的观测差异，并非同一批文件的严格 A/B 结果。
初步按设备状态切换计数曾估算为 6.1 KiB/s；该算法重复计算窗口切换保留的状态，已弃用，最终采用服务器落盘清单和设备确认断点核算。
服务器连续观测后段停滞，因此不据此声称整轮没有瞬时重连；最终文件清单通过独立读取服务器核对。
初版抢占测试脚本在录音中查询 SD 状态收到预期的 EBUSY，修正为结束录音后查询并重新通过验证。

运行时测得堆峰值 45,824 字节；收尾分配 1,656 字节、空闲 80,168 字节。
HTTPS 线程栈峰值 6,024 / 8,192 字节，录音线程栈峰值 26,304 / 32,768 字节。
这些是本轮覆盖路径的高水位，不等于所有场景的上界，也不是续航测量。

## 持续传输速度仍待优化

Mac 使用同一接收端、TLS 1.2、相同 16 KiB 串行分片协议上传 256 KiB 合成数据，测得约 19.93 KiB/s。
这不是设备可达到速度的保证，但说明当前服务端和网络组合可以超过 Clip 的 6–7 KiB/s。

设备连接的服务器 TCP 统计样本 RTT 约 250–285 ms。当前 Zephyr 配置由 16 KiB TX 池和 4 KiB RX 池自动计算窗口，
所用 SDK 源码的默认公式分别为池大小除以 3，即约 5.3 KiB TX、1.3 KiB RX；服务端观测的设备通告接收窗口为 1,365 字节。
这些是定位线索，尚不足以将瓶颈单独归因于 TCP 窗口、2 KiB TLS 写入或服务器确认。

后续优先拆分测量文件哈希、SD 读写、TLS/TCP 写等待、响应等待与服务端持久落盘，
再对发送窗口、TLS 写入粒度及响应发送方式做单变量对照；每次同时检查录音抢占、断点正确性和运行时内存。
本轮没有提高并发、扩大分片、取消持久确认或修改 TLS 证书校验。
