# 空闲自动上传

基于 v0.1.2 的 `CLIP_HTTPS_POC` 构建，保留 USB CDC 与 BLE 控制，关闭 AP 和 USB
磁盘。录音与上传串行执行，录音优先；原录音保留，不更改手机的同步计数。

## 配置与启用

以下控制只接受 USB。默认关闭自动上传；修改网络或接收端前先关闭自动上传，等待
`UPLOAD?` 的 active 为 false。凭据不得放进终端历史、提交记录或公共日志。

| 命令 | 行为 |
|---|---|
| `NETCFG=ssid,password` | 在 RAM 中设置单个 WPA2 网络 |
| `UPLOADCFG=host,port,device,token` | 在 RAM 中设置接收端身份和认证 |
| `UPLOADCLOCK=host,port` | 设置 SNTP 地址；默认 time.cloudflare.com:123 |
| `UPLOADSAVE` | 持久保存完整配置，但不自动改变开关 |
| `UPLOADAUTO=on` | 保存完整配置和开启标志，开始空闲调度 |
| `UPLOADAUTO=off` | 立即禁止新自动任务、取消当前自动任务，并持久保存关闭标志 |
| `UPLOADAUTO?` | 返回开关、暂停、持久化错误、扫描错误、校时和退避状态 |
| `UPLOADCLEAR` | 空闲时清除持久配置及 RAM 凭据，同时关闭自动上传 |
| `UPLOADLIST=0` | 从头分页列出片段的上传状态 |
| `UPLOADLIST=session:segment` | 获取严格晚于该游标的下一页 |

`UPLOADAUTO=on` 本身会保存，不要求先执行 UPLOADSAVE。配置未完整或保存失败时
不会开启。关闭操作即使保存失败也会在本次启动中停止自动任务，并返回错误；此时
不能承诺重启后仍关闭，应修复存储并再次保存或清除。

凭据与开关保存在设备外置 Flash 的 LittleFS settings 中，作为一个版本化、带 CRC
的 `https/config` 值加载；不保存在可移除的 SD 上，不在查询结果中返回密码或令牌。
这是持久存储，不是凭据加密或安全元件。缺失／损坏／字段无效时不自动联网，查询
可看到 config_error。原 settings 加载看门狗仍适用，擦除 settings 会丢失这些配置。

## 调度和恢复

复用原 HTTPS 工作线程，不增加永久队列或线程栈。工作线程以单秒定时等待和手动
任务信号运行；只有事件调度器确认 IDLE、没有录音／暂停会话、其他传输或 OTA 时
才取得上传占用。扫描和网络操作期间都允许 START 请求录音抢占。

扫描真实 SD 时间桶与分组目录，没有原 LIST 的 200 会话上限。只处理已封口、
非空且不超过现有 8 MiB 协议上限的录音；文件名必须与规范路径匹配。缺失／无效
会话元数据、仍标为 recording 的会话和不支持的长度不会自动上传，列表的 eligible
为 false；异常录音文件修复是独立功能。

读取每片段的 `http-N.a/b`。长度和接收端指纹匹配、状态为 uploaded 的文件跳过；
其余文件按会话和片段号轮转，每次处理一个。失败也推进游标，防止一个文件阻塞
后续文件；游标只在 RAM 中，重启后重新扫描持久记录。每次实际上传仍重新哈希并
查询服务器偏移，不能把本地状态当作服务器最新进度。

- 开机加载完成后约 10 秒开始检查；设备仍忙时继续等待。
- START／STOP 活动后留出约 5 秒空闲窗口，再检查；录音结束后无需手动 UPLOAD。
- 成功后约 5 秒处理下一文件。
- 连续失败依次等待 20、40、80、160、300 秒，之后上限 300 秒；成功清零。
- 队列为空约 5 分钟复查；新录音 STOP 会提前唤起。扫描 I/O 错误约 30 秒后复查。
- 录音抢占不计作网络失败。用户执行 UPLOADCANCEL 会暂停本次启动中的自动调度；
  重新执行 UPLOADAUTO=on 解除暂停。该暂停不是持久关闭，关闭须用 off。

部分和失败记录不会删除本地文件。上传途中重启时设备状态可能滞后，但服务器已
落盘检查点决定续传位置。完整上传后的本地标记只证明上次确认成功；服务器后来
丢失数据时，自动跳过策略不会自行发现，周期对账不属于本阶段。

## 时间与证书

开机不把上次保存的时间当作当前 TLS 时间。联网后通过配置的 SNTP 端点获取时间，
每 6 小时重新校时；USB 注入 UPTIME 可用于受控测试。校时成功也更新原录音时钟。
SNTP 获取失败则本次上传失败并退避；不关闭证书链、主机名或有效期校验。
SNTP 本身没有认证，不能等同于可信签名时间服务；设备断网且时钟未更新时，原有
录音命名时钟仍受既有产品行为约束。

Mac 测试接收端可在原 HTTPS 命令中加 `--clock-port 12345`，并将 UPLOADCLOCK 指向
Mac 的该 UDP 端口。它使用 Mac 系统时间，只用于同一受控局域网；默认不启动。

## 状态列表与兼容性

UPLOADLIST 每页最多两个项目，含 session、segment、state、size、confirmed、eligible
和 state_error；返回 more 和下一页 next 游标。仅空闲可查询，不暴露物理 SD 路径。
分页间若新录音出现在已越过的游标前，重新从 0 扫描即可；不是跨页快照。

原 UPLOADSTATE 保留更详细的单片段身份核对。UPLOAD? 的阶段是最近一次工作状态，
空扫描可回到 idle；历史失败以每片段记录为准。自动任务停止及清理后仍可手动指定
UPLOAD。原普通固件不编入上述模块，AT 命令表仅实验构建扩为 48 槽，完整配置实际
注册 45 个命令；启动注册回归测试防止再次因容量不足而提前退出。
